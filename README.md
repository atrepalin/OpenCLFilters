# OpenCLFilters

Кроссплатформенное графическое приложение для студентов курса **«Программирование специализированных вычислителей»**, предназначенное для разработки, загрузки и запуска **OpenCL-ядер обработки изображений**.

Программа позволяет загрузить изображение, выбрать OpenCL-платформу и вычислительное устройство, загрузить исходный код ядра `.cl`, собрать его непосредственно через OpenCL и применить выбранное ядро к изображению. Результат отображается рядом с исходным изображением.

## Возможности

* работа с OpenCL-платформами и устройствами;
* автоматическое обнаружение доступных OpenCL-платформ;
* выбор конкретного OpenCL-устройства;
* загрузка OpenCL-исходников из файлов `.cl`, `.ocl` и `.opencl`;
* автоматический поиск ядер в загруженном исходном коде;
* выбор ядра для выполнения;
* загрузка изображений в форматах:

  * PNG;
  * JPEG;
  * BMP;
* выполнение OpenCL-ядра над изображением;
* возможность выполнить ядро несколько раз подряд;
* отображение исходного и обработанного изображения;
* измерение времени выполнения OpenCL-вычислений;
* отображение журнала сборки OpenCL-программы;
* вывод сообщений об ошибках OpenCL.

Приложение использует OpenCL image objects формата `RGBA` с 8-битными компонентами. Для запуска ядра изображение передаётся в OpenCL как `image2d`, а размер глобальной рабочей области соответствует размерам изображения.

## Интерфейс

Основное окно приложения содержит панель управления, на которой доступны:

1. **Platform** - выбор OpenCL-платформы.
2. **Device** - выбор вычислительного устройства.
3. **Load .cl** - загрузка исходного кода OpenCL.
4. **Load Image** - загрузка исходного изображения.
5. **Kernel** - выбор найденного в исходнике OpenCL-ядра.
6. **Build** - компиляция OpenCL-программы.
7. **Iterations** - количество последовательных запусков ядра.
8. **Execute** - запуск выбранного ядра.

Ниже отображаются два изображения:

* **Before** - исходное изображение;
* **After** - результат обработки.

Также интерфейс содержит строку состояния и **OpenCL Build Log**, в котором отображается вывод компилятора OpenCL.

## Как работает обработка

После загрузки изображения приложение создаёт два OpenCL-изображения:

* входное изображение;
* выходное изображение.

Затем выбранное ядро получает два аргумента:

```text
0 - входное изображение
1 - выходное изображение
```

Ядро запускается с двумерной глобальной рабочей областью:

```text
(width, height)
```

При указании нескольких итераций выход предыдущего запуска становится входом следующего. После завершения всех запусков результат считывается обратно в память приложения и отображается в интерфейсе.

### Требования к OpenCL-ядру

Для работы с приложением ядро должно принимать первым аргументом входное изображение, а вторым - выходное изображение.

Например:

```c
__kernel void grayscale(
    read_only image2d_t input,
    write_only image2d_t output)
{
    // обработка изображения
}
```

Конкретная реализация алгоритма обработки определяется студентом.

Приложение автоматически анализирует исходный текст и ищет объявления ядер с `__kernel` или `kernel`, после чего найденные имена становятся доступны для выбора в интерфейсе.

## Зависимости

Для сборки используются:

* **C++17**;
* **CMake 4.4** или новее;
* **OpenCL**;
* **OpenGL**;
* **GLFW 3.4**;
* **GLEW**;
* **Dear ImGui**;
* **stb_image**;
* **tinyfiledialogs**.

Большинство библиотек автоматически загружается CMake во время конфигурации проекта через `FetchContent` и `CPM.cmake`.
OpenCL устанавливается отдельно, поскольку приложению необходимы OpenCL headers и библиотека OpenCL. CMake поддерживает несколько способов обнаружения OpenCL, включая явное указание путей, `OPENCL_ROOT`, CUDA Toolkit в Windows и стандартный `find_package(OpenCL)`.

> **Важно:** наличие библиотеки OpenCL само по себе не гарантирует наличие вычислительного устройства. В системе должен быть установлен OpenCL-драйвер/ICD для соответствующего GPU или CPU.

# Сборка

## Общий способ

Проект использует CMake.

После установки необходимых зависимостей выполните:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Исполняемый файл будет создан в каталоге `build`.

Проект собирается с использованием стандарта **C++17**.

## Linux

На Linux для сборки проекта необходимы инструменты разработки, OpenGL-зависимости и OpenCL.

Например, для Ubuntu используются:

```bash
sudo apt-get update

sudo apt-get install -y \
    build-essential \
    cmake \
    pkg-config \
    libwayland-dev \
    wayland-protocols \
    libxkbcommon-dev \
    libx11-dev \
    libxrandr-dev \
    libxinerama-dev \
    libxcursor-dev \
    libxi-dev \
    libgl1-mesa-dev \
    libglvnd-dev \
    opencl-headers \
    ocl-icd-opencl-dev
```

Эти зависимости также используются в автоматической сборке Linux-версии проекта.

После установки зависимостей:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```

Запуск:

```bash
./build/OpenCLFilters
```

## Windows

Для Windows проект собирается с помощью **MinGW** и CMake.

В автоматической сборке используется:

* Windows Server 2022;
* MinGW;
* CMake;
* OpenCL ICD Loader и OpenCL Headers от Khronos.

Если OpenCL установлен в нестандартном месте, его расположение можно передать CMake через `OPENCL_ROOT`:

```bash
cmake -S . -B build \
    -G "MinGW Makefiles" \
    -DCMAKE_BUILD_TYPE=Release \
    -DOPENCL_ROOT="C:/OpenCL"
```

Затем:

```bash
cmake --build build --config Release --parallel
```

Для Windows CMake также предусматривает поиск OpenCL через CUDA Toolkit, если соответствующая установка присутствует в системе.

## macOS

Для macOS используется CMake и компилятор Clang.

Пример конфигурации:

```bash
cmake -S . -B build \
    -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_OSX_ARCHITECTURES="arm64"
```

Сборка:

```bash
cmake --build build --config Release --parallel
```

Проект формирует macOS application bundle (`.app`). В автоматической сборке используется архитектура **arm64**.

# Использование

### 1. Выберите OpenCL-платформу

После запуска приложение автоматически перечисляет доступные OpenCL-платформы и устройства.

Выберите нужную платформу и устройство в верхней панели.

### 2. Загрузите OpenCL-ядро

Нажмите:

```text
Load .cl
```

и выберите файл с исходным кодом OpenCL.

Приложение автоматически найдёт объявления ядер и добавит их в список выбора.

### 3. Загрузите изображение

Нажмите:

```text
Load Image
```

и выберите PNG, JPEG или BMP-файл.

### 4. Соберите OpenCL-программу

Нажмите:

```text
Build
```

OpenCL-программа будет скомпилирована непосредственно выбранным OpenCL-устройством.

Если компиляция завершится ошибкой, подробности можно посмотреть в разделе:

```text
OpenCL Build Log
```

Программа всегда получает build log после попытки сборки.

### 5. Выберите ядро

Если в `.cl`-файле найдено несколько ядер, нужное ядро можно выбрать в поле **Kernel**.

### 6. Запустите обработку

Укажите количество итераций в поле:

```text
Iterations
```

и нажмите:

```text
Execute
```

После выполнения результат появится в области **After**.

В строке состояния отображаются название запущенного ядра, количество итераций и время выполнения.

# Для студентов

Проект предназначен прежде всего как учебный инструмент для экспериментов с **OpenCL** и специализированными вычислениями на изображениях.

Студент может сосредоточиться на разработке OpenCL-ядра, не реализуя самостоятельно оконный интерфейс, загрузку изображений, выбор OpenCL-устройства и базовую инфраструктуру запуска.

Типичный цикл работы:

```text
Изображение
     │
     ▼
OpenCL Kernel (.cl)
     │
     ▼
Build на выбранном устройстве
     │
     ▼
Execute
     │
     ▼
Обработанное изображение
```

Это позволяет удобно сравнивать результаты различных алгоритмов и исследовать производительность OpenCL-вычислений.
